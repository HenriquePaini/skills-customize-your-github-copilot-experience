
# 📘 Assignment: Jogo da Forca

## 🎯 Objective

Construa o clássico jogo de adivinhar palavras usando strings, loops, condicionais e entrada de dados do usuário em Python. O jogador deverá revelar uma palavra oculta antes de esgotar o número máximo de tentativas incorretas.

## 📝 Tasks

### 🛠️ Implementação do Jogo da Forca

#### Descrição
Implemente um jogo da Forca que selecione uma palavra oculta e permita ao jogador adivinhar suas letras até vencer ou perder.

#### Requisitos
O programa concluído deve:

- Selecionar uma palavra aleatoriamente de uma lista predefinida.
- Aceitar palpites de letras e mostrar o progresso atual no formato `_ _ _`.
- Rastrear o número de tentativas incorretas restantes.
- Encerrar quando a palavra for adivinhada ou quando as tentativas incorretas se esgotarem.
- Exibir uma mensagem indicando vitória ou derrota.
